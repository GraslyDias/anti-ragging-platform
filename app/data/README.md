# Dummy Data for Anti-Ragging Platform

This directory contains dummy data and instructions for using placeholder images in the platform.

## Required Image Structure

For the dummy data to work correctly, please create the following directory structure in the `public` folder:

```
public/
├── images/
│   ├── avatars/
│   │   ├── avatar1.png
│   │   ├── avatar2.png
│   │   ├── avatar3.png
│   │   ├── avatar4.png
│   │   └── avatar5.png
│   ├── posts/
│   │   ├── ragging1.jpg
│   │   ├── ragging2.jpg
│   │   ├── ragging3.jpg
│   │   ├── ragging4.jpg
│   │   ├── ragging5.jpg
│   │   └── ragging6.jpg
│   └── banners/
│       └── banner-overlay.jpg
```

## Placeholder Images

You can use any appropriate images for:

1. **Avatars**: Profile pictures for users
2. **Post Images**: Images related to ragging incidents or educational institutions
3. **Banner Images**: Background images for page headers

## Sources for Free Images

You can find free images from sites like:

- [Unsplash](https://unsplash.com/)
- [Pexels](https://www.pexels.com/)
- [Pixabay](https://pixabay.com/)

## Note

Ensure that all images used are copyright-free and appropriate for the sensitive nature of the platform.
